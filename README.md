# Institutional Knowledge Hub 📚

Exercise: Scale Institutional Knowledge Using Copilot Spaces

## Overview

A modern, responsive web UI for managing and sharing institutional knowledge across your organization. This platform helps teams document, discover, and scale their knowledge effectively.

## Features

- **🔍 Real-time Search** - Search across all articles, titles, and categories
- **📁 Category Filtering** - Filter by Onboarding, Development, Deployment, Testing, Security, and Architecture
- **📱 Responsive Design** - Works on desktop, tablet, and mobile devices
- **⚡ Interactive UI** - Smooth animations, hover effects, and keyboard shortcuts
- **📊 Statistics Dashboard** - Track articles, contributors, categories, and views

## Getting Started

### View the UI

Simply open `index.html` in your web browser, or serve it with any static web server:

```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx serve

# Then open http://localhost:8080 in your browser
```

### File Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `script.js` - Interactive features and functionality

## Usage

### Search
- Type in the search box to filter articles in real-time
- Use `Ctrl/Cmd + K` to focus the search box
- Press `Escape` to clear the search

### Filter by Category
- Click any category in the sidebar to filter articles
- Click the "Categories" heading to show all articles

### Keyboard Shortcuts
- `Ctrl/Cmd + K` - Focus search
- `Escape` - Clear search and show all articles

## Technologies

- Pure HTML5
- CSS3 with CSS Variables and Flexbox/Grid
- Vanilla JavaScript (ES6+)
- No external dependencies or frameworks required
