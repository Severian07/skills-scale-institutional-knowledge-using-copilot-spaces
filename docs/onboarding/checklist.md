# New Developer Onboarding Checklist

Complete this checklist during your first week to ensure you have everything you need to be successful.

## ✅ Pre-Day 1

- [ ] Receive offer letter and accept position
- [ ] Complete HR paperwork
- [ ] Receive company equipment (laptop, etc.)
- [ ] Receive welcome email with first-day instructions

## ✅ Day 1: Access & Setup

### Accounts & Access
- [ ] Set up company email account
- [ ] Join team communication channels (Slack/Teams)
- [ ] Get added to GitHub organization
- [ ] Request access to necessary repositories
- [ ] Set up VPN access (if applicable)
- [ ] Access project management tools (Jira, etc.)

### Meet the Team
- [ ] Introduction meeting with manager
- [ ] Meet your onboarding buddy/mentor
- [ ] Team introduction in standup or team meeting
- [ ] Review team structure and roles

### Initial Setup
- [ ] Review company handbook
- [ ] Read code of conduct
- [ ] Set up development environment (see [dev-setup.md](./dev-setup.md))
- [ ] Clone main repositories

## ✅ Day 2-3: Learning

### Documentation
- [ ] Read architecture overview
- [ ] Review coding standards
- [ ] Understand git workflow
- [ ] Learn code review process
- [ ] Read API documentation

### Codebase Exploration
- [ ] Run the application locally
- [ ] Explore repository structure
- [ ] Review recent pull requests
- [ ] Understand build and test processes
- [ ] Review deployment procedures

### Training
- [ ] Complete required security training
- [ ] Complete compliance training
- [ ] Watch onboarding videos (if available)

## ✅ Day 4-5: First Contributions

### Getting Started
- [ ] Pick a "good first issue" from backlog
- [ ] Set up feature branch
- [ ] Make first code change
- [ ] Write tests for your change
- [ ] Submit first pull request
- [ ] Respond to code review feedback
- [ ] Merge your first PR

### Team Integration
- [ ] Attend daily standup
- [ ] Participate in team meeting
- [ ] Schedule 1:1s with key team members
- [ ] Ask questions in team channels

## ✅ Week 2: Building Momentum

- [ ] Take on more complex tasks
- [ ] Review others' pull requests
- [ ] Contribute to documentation
- [ ] Identify areas for improvement
- [ ] Start working on sprint tasks

## ✅ First Month Goals

- [ ] Complete 5+ pull requests
- [ ] Understand core features of the application
- [ ] Know when to ask for help and who to ask
- [ ] Contribute to at least one team discussion/decision
- [ ] Identify one improvement to suggest
