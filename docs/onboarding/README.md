- Set up development environment

### Day 2-3: Learning

- Explore the codebase

### Day 4-5: Contributing

- Attend team meetings

- **Ask Questions**: No question is too small
- **Take Notes**: Document your setup process
- **Pair Up**: Shadow experienced team members
- **Be Patient**: It takes time to get fully up to speed
